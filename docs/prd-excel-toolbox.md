# PRD · Excel 工具箱（功能 4）

## 目标
把零散的 Excel 操作收成一个 **tab 切换的工具箱**，覆盖客服高频痛点。统一"选表 → 配置 → 预览 → 执行 → 下载"骨架，避免每功能单开一页。

## 现有基础
- `ExcelPrepPage` 已是"体检/整理"（选表 → 校验 → 输出 `原名_已整理.xlsx`），可并入"去重 / 问题导出"。
- 实例配置里已有"Excel 匹配合并"（按单号合并物流表），可前移成独立工具。
- 后端 `openpyxl` 路由可复用/新增。

## 关键设计变更（用户优化）
- **关键列动态化**：合并/补全的"匹配关键列"不再是固定两列，而是**可增删的匹配列列表**（每行 = 主表列 ↔ 来源表列），支持多键联合匹配（如 订单号 + 买家 同时对齐）。
- **补全字段动态化**：补全来源列用可增删的 chip 列表，不预设固定列。
- **新增「生成新表」工具**：选源文件 → 勾选要保留的列（可重排）→ 产出**只含所选列的新表**，解决"按选择的生成新表格"需求。

## 子工具（v1 优先级）
| 优先级 | 工具 | 入参 | 出参 |
|---|---|---|---|
| 高 | 合并 / 补全 | 主表 + 来源表 + **动态匹配列列表**(多键) + **动态补全字段列表** | 合并后 xlsx |
| 高 | 生成新表（列选择） | 源文件 + 勾选保留列(可重排/重命名) | 只含所选列的新 xlsx |
| 高 | 按业务键去重 | 文件 + **动态业务键列列表** | `_已去重.xlsx` |
| 高 | 格式互转 | 文件 + 目标格式(xlsx/csv) | 转换后文件 |
| 中 | 按列拆分 | 文件 + 拆分列 | 多文件(每值一个) |
| 中 | 问题行导出 | 文件(走体检) | 问题行 xlsx/csv |
| 中 | 条件筛选导出 | 文件 + 列 + 条件 | 子集 xlsx |

## 统一骨架
- **布局（用户优化）**：采用**左侧工具栏导航 + 右侧工作区**的"工具箱"结构，而非顶部 tab。左侧按分组（整理 / 转换）列出 7 个工具，点选切换右侧工作区；比 tab 更清晰、易扩展。
- 工作区流程：`选择文件 → 参数配置(按工具不同，**列配置均可动态增删**) → 预览前 N 行 → 执行(后端) → 下载`。预览与执行复用现有 `useExcel*` hooks 风格。列配置以数组形式在参数里传递（列数由用户决定，不写死）。

## 数据/状态
- 前端：当前 tab、所选文件、参数、预览数据、执行结果（沿用现有 `PrepReport` 思路）。
- 后端：复用 `excel_prep` 路由；新增 `excel_merge` / `excel_dedup` / `excel_convert` / `excel_split` 等端点（openpyxl 实现，纯本地、不联网）。

## 验收标准
- [ ] tab 切换（合并/补全、生成新表、去重、互转、拆分、问题导出、筛选导出），各能跑通"选表→执行→下载"。
- [ ] **合并/补全的匹配关键列可动态增删（多键），补全字段可动态增删**。
- [ ] **「生成新表」可按勾选列产出只含所选列的新表**。
- [ ] 共享预览骨架（前 N 行表格 + 执行日志/问题清单）。
- [ ] 合并/去重/互转 覆盖 80% 场景并稳定；拆分/问题导出/筛选导出可用。
- [ ] 原文件只读，产出带后缀新文件（不覆盖）。
- [ ] 后端路由有 pytest（参考现有 `test_excel_*`）。
