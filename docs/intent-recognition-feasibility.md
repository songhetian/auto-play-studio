# 意图定位（Intent Locate）方案可行性评估

> 需求来源：素材库「基于意图的快速识别」——用户输入一句自然语言（如「检查是否遗漏配件」），
> 系统自动定位相关画面并高亮，省去从头翻素材。
> 评估日期：2026-10；结论：**离线启发式可行，作为当前版本实现方案**；LLM 视觉作为远期可选项。

---

## 1. 两种候选方案

| 维度 | A. 离线启发式（已选） | B. LLM 视觉理解 |
| --- | --- | --- |
| 原理 | 对素材名 / 标签 / OCR 文本做意图句关键词 n-gram 重叠打分，按召回率排序 | 把素材图送视觉模型，模型理解语义后返回匹配画面 |
| 依赖 | 仅前端 + 已有素材元数据，零外部服务 | 视觉大模型 API（多模态）、图片外传、计费 |
| 离线可用 | ✅ 完全离线，桌面端无网也能用 | ❌ 必须联网调用 |
| 延迟 | 毫秒级（纯字符串计算） | 秒级（每张图一次推理） |
| 成本 | 0 | 按调用量计费，素材库大时显著 |
| 隐私 | 素材不出本机 | 素材图需上传第三方 |
| 准确率上限 | 受限于文件名 / 标签质量（命名规范时高，命名随意时低） | 语义理解强，能认出「没写名字但画面里确实缺了配件」 |
| 实现复杂度 | 低（纯函数 `intentLocate.ts`，可单测） | 高（需接入模型、限流、重试、降级） |

---

## 2. 离线启发式为什么可行

1. **素材命名在本项目里天然带意图信号**：监控类素材通常就叫「配件齐全」「缺螺丝」「到货扫码处」，
   标签（tag）也是运营自己打的（如「视频帧」「目标图」）。意图句的词（配件 / 遗漏 / 扫码）与这些
   文本高度重叠，n-gram 召回率排序能稳定把最相关素材顶到前面。
2. **定位 ≠ 识别**：用户要的是「快速找到那几张」，不是「模型判断画面里有什么」。
   排序把候选前置、命中项加 `ring-2 ring-primary` 高亮，就已达成「不用从头翻」的目标。
3. **可解释、可单测**：`locateByIntent` 是纯函数，关键词拆解与排序规则都写死在测试里，
   行为可预期、不漂移，符合本项目「行为可验证」的 TDD 纪律。
4. **零新增基础设施**：不引入模型服务、不改打包链路、不动 Electron 桥，向后兼容。

### 召回率计算（已落地）
- 把意图句拆成中文 2-gram + 单字兜底 + 英文按词，去重得到 `terms`
- 每个素材的可检索文本 = 名字 + 标签（OCR 文本若入库可并入）
- `recall = matched.length / terms.length`，按降序排序；`recall=0` 的素材不进命中集

## 3. 边界与已知局限（必须如实告知）

- **命名垃圾进、垃圾出**：若素材叫「新建文件夹(3)」「image_001」，启发式无能为力。
  缓解：引导用户在详情弹窗里改名 / 打标签（已有「改名」入口），并保留关键词搜索作为兜底。
- **同义词不识别**：意图说「螺丝」但素材标「螺栓」，n-gram 不匹配。
  缓解（已落地 + 可自定义）：`src/lib/intentLocate.ts` 的 `SYNONYM_GROUPS` 轻量同义词表（螺丝↔螺栓↔螺钉）
  作为**内置默认**；用户可在素材库「同义词管理」弹窗里直接增删同义词组 / 词，持久化到
  `localStorage`（跨会话记住，见 `src/stores/synonymStore.ts`），经 `buildSynonymMap` 转成查表后作为
  `locateByIntent` 第 3 参覆盖默认 —— **无需改代码重打包**。
  匹配时每个意图词借同义词命中，但召回率分母仍用**原意图词数**，不会因同义词翻倍污染分数。
- **画面语义不可见**：启发式只看文字元数据，看不懂「图里其实缺了东西但名字没写」。
  这正是 LLM 视觉的强项——属方案 B 的领地，本版不覆盖。

---

## 4. 何时该升级到 LLM 视觉（升级判据）

满足以下任一条件时，离线启发式不再够用，应评估方案 B：
1. 用户大量反馈「明明有这张图但定位不到」，且主因是命名不规范、无法靠改名解决；
2. 出现「按画面内容而非文件名找图」的硬需求（如「找出所有背景偏红的海报」）；
3. 素材规模与调用频度使人工打标签成本高于模型调用成本。

升级路径（非破坏性）：`intentLocate` 保持为「离线快速预筛」，在预筛置信度低 / 命中数为 0 时，
再异步调用视觉模型做二次精排——两层可并存，不推倒重写。

---

## 5. 结论

- **可行性：通过。** 离线启发式在当前素材库（命名规范 + 标签）下，足以实现「意图 → 快速定位并高亮」。
- **已交付**：`src/lib/intentLocate.ts`（纯函数 + 10 个单测）、`AssetLibraryPage` 接入意图输入框与命中横幅、
  `src/stores/synonymStore.ts` + 素材库「同义词管理」弹窗（用户可 UI 自定义同义词表，持久化到 localStorage）。
- **不做的**：本版不接 LLM 视觉；将其列为条件触发的远期增强，避免为低频场景引入联网与计费依赖。
