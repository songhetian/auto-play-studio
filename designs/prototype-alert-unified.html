现状：同一次命中会先弹右下横幅（会自己消失），再弹系统 Toast，配色/图标/文案三处都不一样，像两个软件。 改后：同一个事件在三层里用同一配色、同一图标、同一标题句式，只是形态不同（横幅轻、模态重）。

落地要点（改代码时按此来）

① 截图（要动引擎 + DB）
  • hit_events 加 snapshot 字段存路径（不存 base64，会把库撑爆）
  • monitor 命中时已持有 frame，裁命中区存 jpg（复用素材库目录）
  • API 暴露快照地址，命中页 + 提醒框显示缩略图
②③④（纯前端，当天可完）
  • 把分类色/图标/标题句式抽成 alertTone 单一真源，三层共用
  • 提醒框加倒计时进度条（剩余时间可视化）
  • 同类命中在队列里聚合；敏感词不聚合

建议：②③④ 一起做（纯前端、一小时内完、立刻解决"割裂感"）；① 单独一轮（要动引擎与 DB 迁移）。
