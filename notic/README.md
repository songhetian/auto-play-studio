# 屏幕内容监控卫士（出现设定图片触发告警）

Windows 桌面纯 Python 应用：实时监测屏幕，当你**预先设置的目标图片出现在屏幕上**时，立即弹窗并播放告警声音。

> 与"检测拖拽/截图动作"不同，本工具基于**目标图模板匹配**：在任何屏幕画面里查找你设定的图片，出现即告警。

## 功能特点

- **整屏 / 局部双模式**：每个监控区可选"整屏监控"（目标图出现在屏幕**任意位置**即告警）或"局部监控"（只在框定的屏幕子区域中查找）。
- **目标图模板匹配**：用 OpenCV 模板匹配在画面中定位目标图，自动给出出现位置。
- **可配置多个监控区(Zone)**：每个区独立绑定目标图、独立开关、独立相似度阈值、独立范围。
- **播报期间暂停检测，播完画面仍在则续播**：适合"目标一直停留"的持续告警场景——播报（弹窗+声音）约 7 秒，期间停止检测；播完后若画面仍在则再次告警，画面消失则自然停播，既不刷屏也不会漏。
- **目标图多种来源**：从图库选择（图片管理已上传）、从区域截图、从文件导入、从剪贴板粘贴（Ctrl+V）、直接拖拽图片到预览框。
- **图片管理（图库）**：主界面"图片管理"可浏览缩略图、预览大图、一键导入、删除（被监控区引用的会保护）。上传后建监控区时即可"从图库选择"直接选它。
- **声音告警**：支持 **mp3 / wav** 自定义声音，可在"告警设置"里**试听**；未上传声音时自动用系统语音合成"出现目标图片 请查看"（连读 3 遍）。
- 驻留系统托盘，后台运行；扁平蓝调(#2455D9)、浅色背景、普通字重界面。

## 运行前准备

Python 3.9+（推荐 3.13）。图像依赖已就绪（OpenCV、numpy、mss、PyQt5）。

```powershell
python -m pip install -r requirements.txt
```

依赖：`PyQt5`（界面/托盘/弹窗）、`opencv-python`（相似度计算）、`numpy`（像素运算）、`mss`（高速抓屏）。

## 启动运行

```powershell
python run.py            # 启动并显示主界面
```

- 托盘图标左键/菜单 → 打开主界面；菜单"退出"才真正退出，关窗仅最小化。

## 使用步骤

1. 打开主界面，点右上角 **"＋ 新增监控区"**。
2. 选**监控范围**：整屏监控（屏幕任意位置出现目标图即告警）或局部监控（需框选一个屏幕子区域）。
3. 设置**目标图片**（出现它即告警），支持任一种：
   - **从图库选择**：直接选你在"图片管理"里上传好的图片（推荐）；
   - **从区域截图**：抓取框选区域当前画面为目标图；
   - **从文件导入 / 从剪贴板粘贴(Ctrl+V) / 拖拽到预览框**。
4. 调好**出现相似度**（整屏建议 ≥65–80%，局部 ≥85%），填写名称，保存。
5. 主界面即可看到该监控区卡片。当目标图出现在相应范围并达到阈值 → 右上角弹窗（淡入淡出）+ 播放声音（mp3/wav 或默认合成语音）；播报约 7 秒暂停检测，播完画面仍在会继续告警，画面消失则回到静默监测。

## 告警声音设置

- 主界面 **"告警设置"** 里选择 mp3/wav 声音文件并可 **▶ 试听**。
- 若未设置声音文件，则自动用 Windows 自带语音（System.Speech）合成默认文案 `出现目标图片 请查看`，连读 `alert.text_repeat` 遍（默认 3），无需额外依赖。

## 配置 `config.json`

```json
{
  "general": { "run_monitoring": true, "poll_interval_ms": 500 },
  "alert": {
    "popup_enabled": true,
    "popup_timeout_ms": 7000,
    "play_sound": true,
    "sound_file": "",
    "default_text": "出现目标图片 请查看",
    "text_repeat": 3
  },
  "zones": [
    {
      "id": "z1", "name": "充值成功画面", "enabled": true,
      "scope": "full",
      "rect": [],
      "reference_image": "zones/z1.png",
      "hit_threshold": 0.7
    }
  ]
}
```

- `zones[].scope`：`"full"`（整屏任意位置）或 `"region"`（只在 `rect` 内）。
- `zones[].rect`：局部监控时为目标物理屏幕区域 `[x, y, width, height]`；整屏可为空。
- `hit_threshold`：目标图匹配相似度 ≥ 此值判定"出现"→ 告警（整屏建议 ≥0.65–0.80，局部 ≥0.85）。
- `alert.popup_timeout_ms`：单次播报最低保持时长（弹窗停留/播报暂停检测的基础节奏，默认 7000≈7s）。
- 目标图保存在 `zones/` 目录。GUI 所有改动会自动写回 `config.json`。

## 架构与模块交互

```
 mss 抓取虚拟全屏 (后台轮询线程, ScreenMatcher.grab_full)
        ▼
 MonitorEngine 遍历启用区域 → 读参考图(目标图)
   → ScreenMatcher.match_template 在整屏或局部区域定位目标图 → 最高相似度
   → 相似度 ≥ hit_threshold → emit DetectionEvent（播报中 reporting 则跳过本轮）
        ▼
 EventHub → Announcer(QTimer 协调, 主线程)
        │  1. engine.begin_reporting() 暂停检测(约7s)
        │  2. AlertPopup(右上角弹窗, 平滑淡入淡出)
        │  3. sound.play(自定义 mp3/wav，或用系统TTS合成"出现目标图片 请查看")
        │  4. 播放结束且达到最低时长 → engine.end_reporting() 恢复检测
        ▼
 恢复后若画面仍在 → 下一轮再次命中 → 续播；画面消失 → 自然停播
        ▲
        │ 热更新（zones 增删改、开关、阈值）
 ConfigManager(zones 持久化 + 变更监听)  ⇦  MainWindow/ZoneDialog/GalleryDialog/AlertSettingsDialog/RegionSelect
```

- 一次抓屏服务所有监控区，保证实时（默认每 500ms 轮询，可在 `general.poll_interval_ms` 调整）。
- 检测逻辑在后台线程，UI 由 Qt 信号调度到主线程，线程安全；播报期间引擎自动暂停，避免在报警同时继续误报。
- 复用：`EventHub`/`sound`/`alert_popup`；`ConfigManager` 支持 zones(list) 读写与监听；`GalleryDialog` 提供图片管理。

## 手动验证

不依赖真机可直接跑离线自检（相似度算法 + 告警文案拼接 + 配置读写）：
```powershell
python selftest.py
```

真机确认：新建监控区并"从区域截图"，先切走目标画面（确保未告警），再切回目标画面 → 右上角弹窗淡入 + 出声（默认语音"出现目标图片 请查看"×3 或自定义 mp3/wav）；播报约 7 秒内检测暂停，若画面持续停留会再次告警，切走画面则回到静默监测。

## 说明

- 相似度为整块像素级均值比对，屏幕画面稳定的场景高度可靠；轻微抗锯齿/缩放由统一预缩放缓解。
- 画面出现的光照/缩放/窗口层级变化会降低相似度，若需更高容错可适当下调"出现相似度"。
- 本工具在本机实时监测，无需网络/云端；DPI 缩放下框选坐标会自动换算为物理像素保证抓取一致。
